# 医学美容设计教学平台设计说明

## 项目定位

本平台由重庆建筑科技职业学院智慧康养学院定制，用于医学美容技术专业的面部美学比例与对称性教学。首版聚焦校内演示和课堂示范，采用完全本地的合成人像、分析数据与评分规则，不依赖在线模型或 draw.io 服务。

## 教学闭环

1. 载入示范案例：读取本地合成人像，不包含真实个人信息。
2. 智能辅助分析：展示三庭、五眼与面部中轴参照，结果明确标记为教学示范。
3. 方案标注练习：学生拖动轮廓关键点，并选择规范的观察表述。
4. 学习报告：汇总当前画布、分析结论、四维评分和改进建议。

## 页面结构

- 顶部：学校品牌、平台名称、本地环境状态、报告入口和重置入口。
- 左侧：四步教学任务与任务进度。
- 中部：合成人像 SVG 标注画布、分析图层和教学观察选项。
- 右侧：比例分析、对称性判断、标注规范、表达完整四维量表。
- 报告：页面内预览，不提供下载、上传或患者档案功能。

## 数据与评分

页面状态保存在浏览器本地存储。评分满分 100 分，四个维度各 25 分；得分只取决于步骤完成度、图层状态、轮廓点调整和观察结论，因此同样操作始终得到同样结果。

## 安全边界

- 仅使用合成人像和教学观察语言。
- 不提供医疗诊断、治疗决策、效果预测、注射剂量或手术参数。
- 不读取医学美容专用 Prompt 中的临床治疗内容。
- 固定展示“用于教学示范，不用于医疗诊断、治疗决策或效果预测”。

## 验收

生产构建在本地端口 6001 运行，入口为 `/zh/medical-aesthetic`。断开网络后，案例、标注、评分和报告仍可完整运行。主要验收 Chrome、Edge 和 Safari，覆盖 1920×1080 与 1366×768。
